# Plant Haven

A Next.js app showcasing a calm plant discovery experience with animated UI and curated plant pages.

## Available scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the app for production
- `npm start` - Run the production build

## Pages

- `/` - Home page with featured plants
- `/plants` - Plant collection list
- `/plants/[slug]` - Plant detail pages
- `/about` - About the garden experience

## Notes

- Built with Next.js App Router
- Uses `framer-motion` for subtle animations
- Styled using global CSS and modern glassmorphism design
